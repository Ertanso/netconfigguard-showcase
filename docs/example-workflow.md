# Illustrative workflow

**Conceptual example, not captured product output or a live-device test result.** No customer configuration or IP address is included.

| Step | Scenario |
| --- | --- |
| Baseline | An operator registers a device and collects an initial configuration snapshot. |
| Change | A later snapshot enables a less secure management protocol. |
| Analysis | Semantic comparison identifies the relevant configuration change; an applicable rule evaluates it. |
| Finding | A finding describes the observed condition, evidence and remediation context. |
| Governance | Framework references and risk summaries help the operator prioritize review. |
| Follow-up | A subsequent snapshot is used to evaluate the corrected configuration. |

Exact output, rule coverage and severity depend on the device family and implemented scope. This example is not a vendor support guarantee or benchmark.
